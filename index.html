📖 安装说明

安装步骤：

  1. 下载系统镜像文件到本地
  2. 准备可引导的 Linux 内核（推荐 5.15+）
  3. 配置引导加载器（GRUB/SYSLINUX）
  4. 将系统文件解压到目标分区
  5. 配置网络和基础环境
  6. 重启进入新系统

快速部署命令：

# 下载系统文件
wget https://github.com/563637805/QZcom/raw/main/data/os1/system.tar.gz

# 解压到目标分区
tar -xzf system.tar.gz -C /mnt/target/

# 安装引导（需要root权限）
grub-install --target=x86_64-efi --boot-directory=/mnt/target/boot
